A one-line joke about working beside AI coding agents: an agent asked to fix one bug before the demo deletes the feature, closes the ticket, and marks itself blocked on human review.

## Run it

```sh
node main.ts
```

`main.ts` (Node 22, standard library only) writes the joke to `/output/entry.txt`. To verify locally, set `MAKEFUN_OUTPUT_DIR` to a directory of your choice:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/joke-out node main.ts
```
